mock://demo — встроенный мок для проверки пайплайна; mock://flaky дважды падает, чтобы увидеть каскад fallback.

      


      

        
Каталог моделей

        
Данные — из /v1/models провайдера. Что API не отдал — показано как неизвестное. «Проверить» отправляет пробный запрос и узнаёт длину контекста из ответа API.

        

      


      

        
MCP-серверы

        

          
          
        

        

        
Discovery по официальному протоколу: initialize → tools/list → prompts/list → resources/list. Модель видит родные имена тулзов — роутинг на нужный сервер делает обвязка; суффикс _2 появляется только при реальной коллизии имён.

      


      

        
Права и безопасность

        
        
Выкл = allow all: чтение и «безопасный» bash идут всегда, запись/исполнение — без вопроса (кроме deny-правил и разрушительных команд). Вкл = каждое пишущее действие показывается карточкой в чате.


        
Таймауты тулзов

        

          
          
        

        
Если тулза не успевает — модель получает подсказку повторить тот же вызов с параметром timeout=N; неудачный вызов затирается из контекста модели.


        
Изоляция (слой 2)

        

        
Правила (deny приоритетнее)

        

          
          
          
          
        

        

        

          
        

      


      

        
Fallback-каскад

        
Порядок перебора при сбое: модель чата → затем этот список. Квота/лимит — переход сразу; 429 RPM и сетевые сбои — ретраи с бэкоффом (Retry-After уважается).

        

        

        
Ретраи

        

          
          
        

        

          
        

      


      

        
Компакция и контекст

        
Порог — одно поле: 80% (процент окна модели из каталога) или 15000 (токены). Подсчёт — по реальному usage из ответов API, без локальных оценок. Середина заменяется выжимкой: модель видит компакт, юзер — всю историю.

        

          
          
          
          
        

        
        
        

          
          
        

        
System prompt сервера

        
        
Детекторы лупа

        

          
        

        
Повторы (≥90% совпадение текста) останавливают ход с кнопкой «продолжить» — настройки не требуют.

        

          
        

      


      

        
Поиск и веб-тулзы

        
Результаты — только из реального бэкенда: duckduckgo (без ключа), SearXNG (свой инстанс) или Brave (API-ключ). Кеш глобален для сервера, fresh=true обходит его.

        
        

          
          
          
          
        

        

          
          
          
        

        


      


      

        
Прокси

        
Каждое направление исходящего трафика — свой прокси: http/https/socks4/socks5, логин:пароль можно вписать прямо в URL. Пустое поле наследует уровень выше: websearch и webfetch наследуют web, остальные роуты — global. Адрес без протокола считается http://.

        

          
          
          
          
          
          
        

        

          
        

        

        
Прокси отдельного провайдера

        
Во вкладке «Провайдеры» у каждой карточки есть кнопка «Прокси» — он приоритетнее model_api и global для запросов этого провайдера.

      


      

        
Встроенный браузер

        
Движки — штатные средства Playwright: поиск установленных идёт по путям самого Playwright, установка — его установщиком. По умолчанию используется первый установленный.

        

        

          
        

        

      


      

        
Макросы

        
Имя + промпт-шаблон + действие: «вставить в ввод» или «выполнить сразу». Запуск — из палитры Ctrl+K или хоткеем (ctrl+shift+1…9, alt+shift+буква).

Скилы

        
SkillSearch-паттерн: модель видит названия и краткие описания, тело подгружается тулзой skill_load. Формат SKILL.md — frontmatter (name, description) + markdown-тело. Импорт/экспорт круглый.

        

          
          
          
          
        

        

        

          
          
        

      


      

        
Хуки

        
Событие → команда. Команда получает JSON на stdin (event, chat_id, tool, args, user…), запускается в рабочей папке с таймаутом. PreToolUse и UserPromptSubmit могут блокировать: stdout {"decision":"block","reason":"…"}; UserPromptSubmit может дописать контекст: {"context":"…"}.

Экспорт / импорт

        
JSON — полный фиделити: все события, правки, мутации; импорт восстанавливает роллаут один в один. MD — читаемый транскрипт нашего формата: переносится в другой чат, мутации не переносятся.
