# NAgent

[![License: Apache 2.0](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](LICENSE)
[![Python](https://img.shields.io/badge/python-3.12%2B-3776AB.svg)](requirements.txt)

**Self-hosted рабочее место для AI-агента в духе Claude Code — с человеческим веб-интерфейсом в стиле macOS.**

NAgent подключается к любому OpenAI-совместимому провайдеру — локальному (LM Studio, llama.cpp, Ollama, vLLM) или облачному — и даёт агенту всё, что нужно для реальной работы: терминал, файлы, браузер, поиск в интернете. Вы наблюдаете за каждым действием, разрешаете опасное и откатываете результаты.

Никаких облачных бэкендов и телеметрии: один Python-процесс на вашей машине, данные — в локальной SQLite-базе.

---

## Почему NAgent

- **Сервер — мозг, браузер — рендерер.** Вся логика агента, история и состояние живут на сервере (Python 3.12+ / asyncio / aiohttp); веб-клиент — тонкий рендерер без собственной логики. Открыли вкладку на другом устройстве — увидели тот же чат.
- **Модель ничего не выдумывает о себе.** Каталог моделей — прямой проход `/v1/models` провайдера; usage приходит только из ответа API; длину контекста сервер выясняет пробным запросом. Никаких таблиц токенов, цен и эвристик по имени модели.
- **Каждое действие агента видно и контролируемо.** Тулкаллы — компактными карточками; запись файлов и команды — только после вашего разрешения; каждое изменение оборачивается git-чекпоинтом, который можно откатить.
- **Агент работает, а не только болтает.** Планирование перед выполнением, компакция длинных контекстов, сабагенты, фоновые задачи, детекторы зацикливания.

## Возможности

### Чат и агентный цикл
- Стриминг ответов через SSE; «мышление» модели — отдельным сворачиваемым блоком над ответом.
- Ответы рендерятся как **Markdown** (код-блоки, таблицы, списки, ссылки) — прямо во время генерации.
- **План-режим**: агент сначала исследует и предлагает план на одобрение; в контекст модели попадает только одобренная версия.
- Правка и удаление любых сообщений — с историей версий; удаление можно отменить в течение 5 секунд.
- Контекст-метр и счётчики токенов из реальных ответов API.

### Инструменты агента
- **Файлы и терминал** — в рабочей папке (jail: агент не выходит за её пределы).
- **Встроенный браузер** (Playwright): агент водит headless-браузер, а вы видите живой скринкаст, можете кликать и печатать сами; движки chromium/firefox/webkit ставятся из интерфейса.
- **Поиск и чтение веба** с кешированием результатов.
- **Skills** (SKILL.md) и **MCP-серверы** — подключайте расширения без раздувания промпта.
- **Hooks** — свои команды-перехватчики на 5 событий (блокировка тулз, инъекция контекста и т.п.).

### Провайдеры
- Несколько провайдеров одновременно, единый селектор «провайдер + модель».
- Fallback-цепочки: при сбое модели ход автоматически уходит следующей.
- Определение способностей модели с честным «неизвестно» и уточняющим токен-пробом.
- Health-мониторинг провайдеров с латентностью.

### Прокси — для всего исходящего
Отдельная матрица роутов: `global` → LLM-запросы → websearch / webfetch → браузер; http/https/socks4/socks5 с авторизацией. Плюс **персональный прокси у каждого провайдера** (приоритетнее общих роутов).

### Интерфейс
- macOS-стиль: стеклянные панели, тёмная тема, светлая, авто + кастомный CSS.
- Рабочая зона справа: дерево файлов + git-чекпоинты, терминал и браузер; панели тянутся мышью.
- Палитра команд (Ctrl+K), макросы, уведомления и звуки.
- Русский / английский интерфейс.

### Безопасность и совместная работа
- Три режима сервера: **соло / команда / аккаунты** (см. ниже).
- Ключи API шифруются на диске (PBKDF2 + AES-GCM), в команде — запечатываются мастер-паролем.
- Общие проекты с блокировками «locked by user X», FIFO-очередь генераций при нехватке слотов.
- Экспорт/импорт чатов в JSON (без потерь) и Markdown (читаемый транскрипт).
- Опциональный аудит действий, логи сервера с экспортом.

## Запуск

```bash
pip install -r requirements.txt
python run.py                # http://127.0.0.1:8765
```

При первом запуске откроется визард: регистрация владельца → выбор режима → подключение провайдера (host + API-ключ, каталог моделей подтянется сам) → рабочая папка. Дальше — просто пишите в чат.

Переменные окружения:

| Переменная | Значение | По умолчанию |
|---|---|---|
| `AGENT_HOST` / `AGENT_PORT` | адрес сервера | `127.0.0.1:8765` |
| `AGENT_DATA` | папка баз данных | `./data` |
| `AGENT_WORKSPACE` | рабочая папка агента | `./workspace` |
| `AGENT_MASTER_PASSWORD` | разблокировать запечатанные ключи (режим «команда») | — |

На Windows задавайте переменные через `set` (cmd) или `$env:` (PowerShell): `set AGENT_PORT=8080 && python run.py`.

Опциональные зависимости (фичи деградируют мягко, без них всё остальное работает):

```bash
pip install 'httpx[socks]'    # socks-прокси для websearch/webfetch
pip install aiohttp-socks     # socks-прокси для LLM-запросов
pip install playwright        # встроенный браузер (движки ставятся из UI)
```

## Режимы сервера

| Режим | Для кого | Как устроено |
|---|---|---|
| **Соло** | один человек | без логина, один общий набор провайдеров и рабочая папка |
| **Команда** | несколько человек на общем сервере | вход по токенам; общие провайдеры (ключи можно запечатать мастер-паролем); общие проекты с блокировками; очередь генераций при конкуренции |
| **Аккаунты** | у каждого своё | логин+пароль; у каждого свои провайдеры (**ключи зашифрованы его паролем**), чаты, скилы, хуки и папка `data/users/<имя>/workspace` |

Сессии живут в памяти сервера: рестарт — перелогин. Это цена честного шифрования: ключ аккаунтов на диске не хранится.

## Хочу посмотреть, но нет ключа

В визарде (или в Настройках → Провайдеры) укажите host `mock://demo` — это встроенный демо-провайдер с фиктивными моделями. Весь конвейер — стриминг, тулкаллы, разрешения, чекпоинты, каскады — работает как с настоящим; `mock://flaky` вдобавок падает по расписанию, чтобы показать fallback-цепочку в действии. Когда появится настоящий ключ — просто добавьте реального провайдера рядом.

## Архитектура

```
run.py                    точка входа
server/                   «мозг»: цикл агента, провайдеры, тулзы, права,
                          браузер (Playwright), история (SQLite + JSONL),
                          чекпоинты (git), компакция, шифрование, SSE
static/                   тонкий клиент: index.html + app.js + style.css
tests/                    358 смоук-проверок, внешних зависимостей и ключей не нужно
ROADMAP.md                полная спека проекта
```

Клиент не хранит состояния: HTTP для команд, EventSource для потока событий, единственный WebSocket — скринкаст браузера. Закрытие вкладки не убивает агентный ход и браузерную сессию — они живут на сервере.
